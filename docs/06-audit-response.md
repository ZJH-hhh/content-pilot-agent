## 复核命令

```bash
npm test
npm run examples
npm run evaluate:live
npm run verify:live
npm run submission:check
```

前三个模型场景会实际请求配置的模型服务，产生服务商费用；测试与离线示例不调用付费模型。`verify:live` 不发网络请求，重新读取原始 Trace 校验，不只相信 manifest 的 passed 标记。`submission:check` 会明确列出未完成项；其非零退出码是准确反映材料缺口，不是离线工程测试失败。

## 证据边界

逐轮观察哈希能发现记录内部不一致，不能独立证明模型服务商真实性；元数据可审计但不是密码学签名。单元测试使用明确标注的内存合成 fixture，绝不写入 `examples/live/`，不能充当真实决策证据。个人贡献与实际工时以本人说明为准。
