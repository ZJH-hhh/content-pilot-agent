# 需求与成功标准

## 用户和目标

目标用户是需要协调内容创意、素材与制作资源的运营人员。输入内容主题、预算和明确的截止时间，获得有依赖关系的任务计划、真实步骤状态、工具结果、费用明细和已保存方案；无法完成时获得具体原因及缺口。

## 范围

- 提供网页与 HTTP API。网页包括规划工作台、任务历史、素材库及方案/轨迹/产物视图。
- 三份原创合成素材，以主题标签排序。精选方案：素材授权 6 + 内容制作 6 = **12**，预计 90 分钟；轻量方案：2 + 6 = **8**，预计 45 分钟。
- 四种本地工具：素材检索、模板脚本生成、成本和时间估算、方案保存。工具本身的规划费用与等待耗时均为 0；制作时间为方案后续执行时间。真实模型的 API 费用不计入模拟制作预算。
- 运行状态、调用参数、返回摘要、公开行动依据及产物均持久化。预算和截止时间是硬约束。
- 默认离线规则 Mock；可选真实模型循环。模型选择行动，工具负责执行，运行器提供结构和约束，不预设真实模型的行动序列。

## 验收矩阵

| 场景 | 成功标准 | 运行记录 |
| --- | --- | --- |
| 正常完成 | 预算 15，保存 12 单位方案；依赖齐全 | `examples/01-normal.json` |
| 预算动态调整 | 观察到 12 超过预算 10 后转向轻量素材，再估算 8 并保存 | `examples/02-budget-replan.json` |
| 缺预算/时间 | `needs_input`，0 次模型和工具调用 | `examples/03-missing-budget.json`、`04-missing-deadline.json` |
| 工具失败 | 失败明确记录；改选素材；保留检索成功产物 | `examples/05-tool-failure.json` |
| 无可行预算 | 预算 5，返回至少 3 单位缺口，禁止保存 | `examples/06-budget-infeasible.json` |
| 部分成功 | 空素材结果标为 partial，不能继续生成不存在的素材 | `examples/07-partial-result.json` |
| 失败续跑 | 保存失败不撤销成功步骤；重启后仅补跑保存 | `examples/08-save-failure-resume.json`及自动化测试 |
| 步数上限 | 返回 `step_limit`，续跑不重置总上限 | `examples/09-step-limit.json` |
| 时间约束 | 精选超时则选轻量；均超时则报告缺口 | `examples/10-deadline-replan.json`、`11-deadline-infeasible.json` |
| 重复执行 | 相同编号复用同一任务，不追加工具调用或费用 | `examples/12-idempotency.json` |

## 非目标

本地工具不抓取真实版权素材，不生成实际视频，不执行真实支付，不向第三方发布内容。当前不实现多租户认证、生产部署、多 Agent 或生产级 Runtime。模型能否在真实 API 下稳定进行合理重规划，需要配置真实密钥补充评估。
