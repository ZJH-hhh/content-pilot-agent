# AI 辅助与个人贡献披露

## 当前可核实的 AI 使用

本目录内的工程实现由 Codex 完成，范围包括需求拆解、原生 Node.js 服务、状态持久化、模型适配、本地工具、前端 HTML/CSS/JS、原创 SVG 素材图形、测试、实际运行记录生成器和交付文档。没有使用多 Agent 协作。

AI 在当前环境实际执行了测试、离线示例与浏览器交互检查。测试中发现静态资源路径边界错误并修改；不是只提供未经运行的代码。具体证据位于 `examples/` 与评估文档。

文案工具使用本地原创模板；素材库是合成描述，不抓取真实素材。离线决策策略为手写规则测试替身。用户随后在本地配置可用接口，Codex 实际运行 `gpt-6.1-sol` 的正常、预算调整和工具失败三个场景，最终通过行为检查；此前两次未通过的真实运行也完整保留。未把适配器的 mock HTTP 协议测试当作真实模型实验，真实证据位于 `examples/live/runs/`。

## 候选人个人贡献

本人负责项目审计，发现问题并形成审计报告，向 Codex 提供问题与修改反馈。工程实现、代码修订、自动化验证及交付材料整理由 Codex 执行。

本人还提供项目需求与考核约束、在本地配置真实模型接口、提供正式题号，并授权创建 GitHub 仓库及上传项目。本人未声明亲自编写或修改项目代码。

### 工作分工

- 本人：审计项目，发现问题，提供审计报告并提出修订要求。
- Codex：完成 `src/` 中的模型动作循环、四类工具、费用与时间校验、持久化、重复请求去重及失败续跑。
- Codex：完成 `public/` 网页、`tests/` 自动化验证、`examples/` 记录和 `docs/` 交付文档。
- Codex：根据本人审计反馈，增加真实模型行为校验、质量优先提示、有界超时与真实运行元数据，落实修复并运行验证。

## 本轮审计修订中的 AI 工作

AI 增加了真实运行的逐轮模型元数据、观察哈希、三场景行为检查、不可覆盖的运行目录、独立复核命令、提交材料状态检查，以及对应回归测试。真实运行发现提前选轻量与请求超时问题后，AI 修改了质量优先提示和有界超时配置，并重跑验证。元数据与单元测试本身不证明模型效果；本次真实接口实际执行的原始记录独立保存。

本项目中使用 AI 工具的成本、权限和配置与应用中的模拟制作费用是独立事项。仓库不包含真实密钥、手机号或候选人隐私数据。
