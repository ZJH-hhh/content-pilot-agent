# 浏览器实际验证

本地网页入口：`http://localhost:3100`。使用 Codex 浏览器控制实际打开页面并操作。以下结论仅限实际观察到的功能，不替代自动化测试或真实模型效果评估。

| 项目 | 操作 | 结果 |
| --- | --- | --- |
| 首页 | 打开本地网页 | 侧栏、统计、创建表单、四步计划、空态和最近记录正常展示 |
| 提交与预算调整 | 默认主题、预算 10、未来截止时间，点击开始 | 任务由规划中变成已完成，费用 8，结余 2 |
| 实际轨迹 | 点击执行轨迹 | 展示 7 次调用：精选检索/脚本/估算 12，轻量检索/脚本/估算 8，保存成功 |
| 重复执行 | 点击「验证重复执行」 | 提示复用同一任务，无新增调用或费用；工具调用保持 7 次 |
| 素材库筛选 | 打开素材库并选择轻量素材 | 三份素材缩为一份，显示 8 单位、45 分钟 |
| 保存失败 | 高级选项注入保存失败后运行 | 显示未完成、保存工具失败、3/4 步骤有成功产物；两版脚本保留 |
| 失败续跑 | 点击「从已有结果继续」 | 任务完成；Trace 从 8 条变 9 条，仅新增一次保存；第 7 条失败及第 8 条停止仍保留 |
| 历史搜索 | 任务记录中输入「保存失败」 | 仅保留对应任务；输入「城市漫游」可找到原任务 |
| 手机布局 | 390×844 视口截图与 DOM 尺寸核对 | 表单单列、统计两列；viewport=390、pageWidth=375，无超出视口的 main 子元素；测试后恢复默认视口 |
| 刷新持久化 | 刷新页面 | 两条真实测试任务和所选方案仍保留 |
